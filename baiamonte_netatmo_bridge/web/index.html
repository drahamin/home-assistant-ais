HOW IT WORKS

Local first, cloud ready

  1. Pair the Netatmo gateway with Home Assistant’s HomeKit Device or Matter integration.
  2. Keep the normal Netatmo integration for remote access and fallback.
  3. This app matches both copies and selects the healthiest route.
IMPORTANT LIMIT

Local support comes from the hardware

If a model exposes no HomeKit, Matter, or LAN protocol, software cannot make it local. The device remains visible here as cloud-only instead of being misrepresented.
