    COMMISSIONING & RECOVERY

    Complete troubleshooting guide

    Work from left to right; stop as soon as live values return.
    01

    No USB device

    • Use a USB data cable, not a charge-only cable.
    • Connect directly to the Home Assistant host before trying a hub.
    • Power the inverter and reconnect both cable ends.
    • Confirm USB and UART access are enabled for this app.
    • Press Rescan USB after any cable change.
    02

    Device but no reply

    • Stop the previous manual Growatt process or integration.
    • Only one program can own the serial/HID device.
    • Use Auto device and Auto protocol first.
    • Keep 2400 baud for the standard SPF connection.
    • Try the stable /dev/serial/by-id/… path if USB numbering changes.
    03

    Intermittent data

    • Replace long or unshielded USB cables.
    • Avoid an unpowered USB hub.
    • Route USB away from inverter AC and PV wiring.
    • Increase the polling interval if the interface times out.
    • Check the event log for a repeating disconnect pattern.
    04

    Wrong or missing values

    • Select PI30MAX only if Auto chooses the wrong profile.
    • Some firmware does not expose every optional field.
    • Compare voltage and mode with the Growatt front panel.
    • Battery CAN values belong to Baiamonte CAN Monitor, not this USB app.
    • Use the inverter USB app and CAN monitor on separate adapters.
    05

    After a reboot

    • Use a by-id path to survive USB numbering changes.
    • Keep Start on boot and Watchdog enabled in Home Assistant.
    • Keep Automatic updates enabled on the app Info page.
    • Allow about one minute for USB discovery after host startup.
    • Rescan rather than reinstalling the manual configuration.
    06

    Safe commissioning

    • Keep read-only mode enabled during initial migration.
    • Record current values before enabling changes.
    • Change only one setting at a time.
    • Confirm the read-back and Growatt display after each command.
    • Return the app to read-only mode when commissioning is complete.
